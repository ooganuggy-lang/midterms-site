How to read this desk

Ratings are a guide, not a forecast.

“Toss-up,” “Lean,” “Likely” and “Solid” are labels from the snapshot included with this project. A district marked “Not rated” is not being called safe; it simply does not have a curated rating in the supplied snapshot.

Live candidate information comes from the FEC. Polls come from VoteHub. API availability can vary, so the static race snapshot remains visible when live services are unavailable.

About this project. An independent 2026 election dashboard built around a readable race table, full House coverage and live public-data lookups. It is designed as an original editorial interface rather than a reproduction of any publication's site.
Sources. FEC candidate filings; VoteHub polling; supplied race-rating snapshot. Ratings and polling can change frequently.
