About this data: Race ratings and generic-ballot numbers are an illustrative snapshot compiled from public trackers (Cook Political Report, Inside Elections, Sabato's Crystal Ball, 270toWin, RaceToTheWH) as of the date noted above — a point-in-time reference, not a live feed. Candidate filings shown under "Live filings (FEC)" are fetched live from the Federal Election Commission's public API when the backend is connected, ranked by live polling averages from VoteHub where polls exist for the race, or by campaign fundraising otherwise. Primary losers are excluded only where the site operator has manually confirmed a result and added it to the backend's exclusion list — there is no free, live API for actual primary election results, so this list is not automatically complete. Candidate avatars are generated from initials, not real photos — no free API reliably provides verified headshots for every filed candidate. For continuously updated ratings and polling, see Cook Political Report, 270toWin, and Silver Bulletin.
